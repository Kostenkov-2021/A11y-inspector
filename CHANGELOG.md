# Changelog

Все заметные изменения проекта фиксируются в этом файле.

## [Не выпущено]

### Добавлено
- Краевой цикл autoScroll для указательного и нативного перетаскивания: документ, вложенные области, обе оси и RTL; wheel и ограниченный резервный scrollBy при недостаточном продвижении. В отчёте отдельно показаны итерации, время и помощь расширения.
- Общий сценарный интерфейс pattern для всех 30 записей текущего каталога WAI-ARIA APG: распознавание структуры, явно заданные клавиши/модификаторы, русскоязычный typeahead и обязательные постусловия интерактивного шага. Это не заявление о полном аудите всех паттернов.
- Сравнение строковых aria-* атрибутов в expect.attributes, включая aria-valuenow и aria-activedescendant; снимки паттернов до/после и русские названия в отчётах.
- Наблюдение Web Audio через debugger: жизненный цикл контекстов, граф, часы, ограничения и диагностика без подмены API, записи или запуска звука. Работающий контекст не считается доказательством слышимого воспроизведения.
- Действия radio, multiple, listbox и логические состояния ARIA с подтверждением после доверенных событий; постусловия values/selected/expanded/pressed.
- Явные переходы сценария в открытый Shadow DOM и iframe того же origin; ограничения sandbox, CSS transform/zoom и числа контекстов.
- Нативный HTML Drag and Drop через перехват данных сайта и CDP; явно разрешаемая управляемая прокрутка во время жеста, без переноса файлов.
- Наблюдение поздних статусов observe, ограниченный журнал времени/текста/исходного HTML и инвентаризация пользовательских медиаплееров media, включая открытые shadow-root.
- Сопоставление полей без autocomplete по точным нормализованным подписям с разделением форм, контекстов и типов; без сохранения введённых значений.
- Регрессии замены/исчезновения цели, изменения вариантов/optgroup, закрытия popup, тайм-аутов, очистки наблюдателей и новых операций в настоящем расширении.
- Регрессии скрытых потомков статусного сообщения и их появления, запрета клавиш select и восстановления значения обработчиком сайта.
- Сквозные прерывания пользовательского сценария при отключении debugger и закрытии вкладки; отсутствие passed после потери соединения, последующего ввода и оставшихся слушателей.
- Сведения connectionLost/detachReason в охвате workflow и русское объяснение потери debugger в HTML, Markdown и текстовом отчёте.
- GitHub Actions: проверки исходников, UTF-8 и ресурсов Manifest V3, воспроизводимости vendor-файлов и полный браузерный набор Chromium; actions закреплены SHA, права ограничены чтением.
- Конфигурация Dependabot для зависимостей и GitHub Actions; описание следующих проверок и настроек репозитория.
- Регрессии смены документа внутри ввода, скрытого текста потомков, короткого loop, перемотки и блокировки чужого origin/редиректа настоящим расширением.
- Постусловия expect для действий: текст, значение, checked, видимость, доступность и фокус с ожиданием состояния; отчёт различает постусловие, состояние поля и отправку действия.
- Действия checkbox и select с реальными событиями CDP и подтверждением состояния; недоступные, неоднозначные и неподдерживаемые варианты явно отклоняются.
- Наблюдение медиасобытий в автоматических и пользовательских сценариях: ограниченный журнал, измерение потенциально звукового интервала, сведения в JSON и человекочитаемых отчётах.
- Регрессии новых операций и постусловий, отменённых изменений, областей autocomplete, медиасобытий и лимитов; новые операции проверяются и настоящим расширением с debugger.
- Регрессии для неоднозначного check, неподдерживаемого fill, проверки принятого ввода, перетаскивания с прокруткой, отложенных состояний и количественных лимитов.
- Счётчики выборок в coverage основных и сценарных проверок; усечение и нижняя граница размера явно обозначаются в отчётах.
- Явное разделение автоматических проверок и автоматически полученных наблюдений для ручного подтверждения (`assessment`); сведения о фактическом подключении и отсоединении debugger.
- Отдельные результаты успешных проверок ожидаемого текста в пользовательском сценарии.
- Выбор профилей WCAG 2.2 / ГОСТ Р 52872-2019 и доступных проверок AAA; единые статусы замечаний и результатов стандартных тестов.
- Сценарии связанных подсказок hover/focus/Escape и наблюдение изменений статусных сообщений.
- Первичные медиапроверки и наблюдения для аутентификации и альтернатив перетаскиванию.
- Явно разрешаемые JSON-сценарии ввода, кликов, клавиш, указательного перетаскивания и переходов между шагами одного origin, с проверкой ожидаемого текста.
- Сквозной тест загруженного расширения с настоящим debugger в отдельном временном профиле браузера.
- Выключенный по умолчанию сценарный режим: реальный обход `Tab` / `Shift+Tab`, адаптация текста при 320 CSS px (256 CSS px для вертикального письма), увеличение шрифта до 200% и поиск перекрытого фокуса.
- Восстановление временных изменений вкладки после сценарной проверки и явные предупреждения при прерывании или ошибке восстановления.
- Сведения об охвате сценариев в JSON, HTML, Markdown и текстовых отчётах, включая отчёты без замечаний.
- Разрешение `debugger` для сценарного режима; подключение отладчика выполняется только при явном включении режима пользователем.
- Локальный набор из 41 стандартного правила axe-core с русской локализацией: ARIA, доступные имена, язык, таблицы и размер целей по WCAG 2.2, критерий 2.5.8.
- Стандартные проверки элементов ниже видимой области и внутри открытых Shadow DOM.
- Сведения об охвате стандартного набора в JSON-отчёте и явное обозначение результатов, требующих ручной проверки.
- Браузерные регрессионные тесты и воспроизводимая подготовка локальных файлов axe-core.

### Исправлено
- Перед финальным отпусканием указателя проверяется актуальная точка цели; для native drag координаты пересчитываются перед dragEnter/dragOver/drop.
- Составное действие сохраняет привязку к исходному DOM-узлу; замена с тем же селектором и потеря фокуса ввода не приводят к действию над новым элементом или ложному completed.
- Состав, порядок, идентичность и доступность option проверяются между командами; изменение select во время действия прерывает сценарий.
- Периодический пересмотр CSS-видимости статусов включается только в явном observe, чтобы неизменённые сообщения не создавали ложное усечение обычного сценария.
- Снимки статусных сообщений используют тот же отображаемый текст, что check/expect; изменения скрытого и служебного текста не создают ложный кандидат 4.1.3, исходный HTML сохраняется полностью.
- Утрата debugger учитывается через onDetach и проверку собственной сессии до/после инспекций: признак attached у другого отладчика не выдаётся за наше подключение. Потерянная сессия повторно не отсоединяется и не подключается заново.
- Перед каждой командой Input проверяются origin и идентификатор документа. Переходы основного документа на другой HTTP(S)-origin блокируются через Fetch; незавершённая загрузка останавливается перед отключением защиты.
- check и expect.text сравнивают отображаемые текстовые узлы, исключая скрытых потомков и служебные script/style; HTML-снимки не изменяются.
- Короткий loop сохраняет доказательство повторного воспроизведения через краткую наблюдаемую границу цикла; обычные паузы и перемотки не суммируются.
- Переход, завершившийся между шагами, учитывается в журнале и анализе повторного ввода. Случайное указательное попадание во встроенный документ отклоняется; разрешённый same-origin iframe задаётся явно.
- Повторный ввод сопоставляется по нормализованным токенам autocomplete с учётом section/shipping/billing и назначения контакта; кандидат должен быть обязательным пустым полем. В замечании сохраняется основание без введённого значения.
- Длительность медиафайла больше не используется как доказательство наблюдаемого звукового интервала; пауза, ожидание данных, отключение звука и смена источника разделяют интервалы.
- click проверяет попадание до нажатия и повторно после наведения; перекрытые, недоступные и переместившиеся цели не записываются как выполненные шаги.
- Видимость в сценариях учитывает нулевую прозрачность элемента и предков; невидимый текст не подтверждает check.
- Изменения статусов сравниваются с предыдущим текстом и видимостью: изменение только цвета или класса не считается новым сообщением; появление через предка и вставленные сообщения обнаруживаются отдельно.
- check не возвращает passed при неоднозначном селекторе; fill ограничен текстовыми полями и подтверждает фактическое значение.
- Источник и цель drag измеряются после общей прокрутки; выход за общий viewport без явного scroll true отклоняется до нажатия указателя.
- Переполнение 200 узлов наблюдателя сохраняется в охвате, в том числе между пакетами и после завершения шагов.
- Фиксированные задержки 80/150 мс заменены ожиданием состояния layout, документа, текста, ввода и подсказки с ограничением времени; устранена гонка при удалении фрейма во время перехода.
- Шаблоны русской локализации axe-core компилируются при подготовке локальных файлов, а не во время работы расширения под CSP.
- Исключены чистые напоминания по `autocomplete="off"`, `draggable="true"` и предполагаемому движению; синтетический Tab не используется как проверка ловушек.
- Невыполнимые измерения контраста вынесены в `coverage.notTested` и не учитываются как найденные проблемы.
- Убрано фиктивное резервное значение контраста 4.5: недоступность расчёта явно обозначается как невыполненное измерение.
- Обратный клавиатурный обход начинается с конца документа; прямой обход учитывает положительный tabindex. Тесты проверяют посещённые элементы в обоих направлениях.
- Синтаксические замечания разделены по профилям; семантические связи сопоставляются с применимыми критериями вместо безусловного 4.1.1.
- Простой контраст учитывает alpha-композицию; сложные фоны и неподдерживаемая отрисовка явно требуют ручной проверки.
- Убраны замечания только из-за пустой скрытой live region или отсутствия assertive у сообщения, похожего на ошибку.

### Изменено
- Минимальная версия Chromium повышена до 118 с учётом жизненного цикла debugger-сессий service worker.
- Пустой `aria-current` больше не считается безусловной ошибкой; значение `false` не скрывает предупреждение у предполагаемого текущего пункта.
- Проверки текущего пункта учитывают вкладки, точные классы состояния и якорные ссылки.
- Исправлен приоритет `aria-labelledby` перед `aria-label` в резервном вычислении имени.
- Убраны безусловные замечания о декоративном пустом `alt`, длине `alt` свыше 125 символов, нативных `title`-подсказках и отсутствии видимого текста у именованной иконки.
- Устранены дубли стандартных и резервных проверок имён и ролей. Отсутствие индикатора фокуса больше не определяется только по стилям нефокусированного элемента.
- Исправлен подбор контрастного цвета: направление изменения и результат после округления RGB.
- Фоновый запуск ожидает асинхронные проверки, использует `func` в Scripting API и избегает повторного внедрения уже загруженных модулей.
- HTML-код проблемного элемента безопасно сохраняется во встроенных данных автономного HTML-отчёта.
- Исправлено отображение подробностей в автономном HTML-отчёте и обработка JSON-отчётов, содержащих полный HTML проблемного элемента.

## [1.1]

### Добавлено
- Расширен набор проверок по WCAG и ГОСТ Р 52872-2019: заголовок страницы, назначение полей через `autocomplete`, помощь при ошибках в формах, контраст нетекстовой информации, интервалы текста, всплывающий контент, порядок фокуса, клавиатурные ловушки, метка в доступном имени, статусные сообщения и целостность ID-ссылок.
- Добавлена проверка `aria-current` для активных пунктов навигации, ссылок текущей страницы и некорректного использования `aria-selected` вместо `aria-current`.
- Добавлена проверка языка отдельных частей контента: расширение находит текстовые фрагменты, язык которых отличается от языка страницы и требует собственного атрибута `lang`.
- Добавлен локальный модуль `language-detector.js` для определения языка текста без внешних запросов.
- Добавлен модуль `doka-links.js`, который подбирает справочные материалы с сайта [doka.guide](https://doka.guide) по категории и деталям найденной проблемы.
- В отчёты JSON, HTML, Markdown и текстовый формат добавлены ссылки на материалы Doka.
- В интерфейс выбора формата отчёта добавлен Markdown.
- В предпросмотре отчёта добавлены категории новых проверок и блоки со справочными ссылками.

### Изменено
- Версия расширения обновлена до `1.1` в `manifest.json` и popup-интерфейсе.
- `background.js` и `manifest.json` подключают новые вспомогательные модули перед запуском `content-script.js`.
- Генератор отчётов дополняет найденные проблемы полем `guideLinks` со справочными ссылками по найденной проблеме или ошибке.
- Экспортируемый HTML-отчёт сохраняет справочные ссылки внутри автономного файла.

- Проверка изображений без `alt` и декоративных изображений с пустым `alt`.
- Проверка базовой структуры заголовков, семантической разметки и ARIA-атрибутов.
- Проверка клавиатурной навигации и значений `tabindex`.
- Popup-интерфейс для запуска проверки по URL текущей или указанной страницы.
- Генерация отчётов в JSON, HTML и текстовом формате.
- Скачивание отчёта для дальнейшего анализа.
